#Toda vez que inicializar:

-> .venv\Scripts\Activate.ps1
Código de ativação do venv e no prompt precisa aparecer (.venv) verdinho dizendo que está
usando a "caixa de ferramentas" do projeto.



#Aprendizado

-> python -m venv .venv
Esse comando cria um ambiente virtual, algo como um kit de ferramentas especifico para esse 
projeto e não utiliza a biblioteca geral do python.
